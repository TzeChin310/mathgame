# 數學勇者｜星星島闖關

以 Phaser 3 製作的國小數學平台闖關小遊戲，共五關。答對加 10 分，答錯扣 5 分；每關蒐集正確答案星球後即可前往下一關。

## 開始遊戲

用瀏覽器開啟 `index.html` 即可遊玩。遊戲透過 jsDelivr 載入 Phaser 3.90.0，因此首次開啟時需要網路連線。

## 操作方式

- 鍵盤：`←` / `→` 或 `A` / `D` 移動，`↑`、`W` 或空白鍵跳躍。
- 觸控：使用畫面下方的左右與跳躍按鈕；左右按鈕可輕點，也可按住連續移動。
- 答案星球位於地面路線上，移動靠近即可蒐集；跳躍是額外操作。

## 檔案

- `index.html`：遊戲頁面與介面結構。
- `styles.css`：版面、色彩與行動裝置排版。
- `game.js`：Phaser 場景、題目、角色操作與計分。
